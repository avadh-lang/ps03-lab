# Demo script (PS03 mapped)
Start: ./run.sh -> http://localhost:8000 (world: /world, phone: /m, token via "Phone control" button)
1 Reset lab (click twice). Say the PS ask: reproduce a paper, what-if, explain differences, evolving agent team.
2 Run (Fast preset). Point: PaperReader reads the paper claim [D2], Planner picks what-if axes [D5,D14], decision feed shows UCB table [D6].
3 Live curves: memorise then grok, yellow dot [D11,D22]. Oracle strip: ETA + low-odds kill [D16,D19,D23].
4 Parallel runs: baseline, wd=0, wd=0.1, train_frac=0.3 run together [D19].
5 Compare panel: paper claim vs observed, causes from config diff [D13,D24]. Paper epoch is UNVERIFIED, say so.
6 Run again: memory dedup skips done runs [D15].
7 Pin CodeRunner-Literal: real CUDA error -> Debugger fix -> reused later [D4,D11,D15].
8 Approval card: spawn a missing-skill agent, approve/reject [D7,D20]. Phone /m too [D18].
9 Party: click a creature -> task graph, score, lineage [D8,D9,D10,D26]. Rate a run 1-5 to feed reward [D8].
10 /world: battle vs paper claim [D25,D27].
Limits: no Kaggle/Colab, no arbitrary PDF upload, no notes/collab panels, one paper (grokking).
